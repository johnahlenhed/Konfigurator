## 6. Tekniska anteckningar för webbutvecklaren
- GLB-filen innehåller scenens 3D-data och kan laddas som en sammanhållen glTF-resurs.
- Använd objektens exakta namn som identifierare i webbkoden.
- Materialnamn kan användas för att hitta material som ska ändras, exempelvis färg eller metallic/roughness.
- Kontrollera animationernas namn och targets när animationer kopplas till knappar eller andra UI-händelser.
- För interaktiva delar är unika och tydliga namn särskilt viktiga.
